## 2. Fixes needed for this batch

- **Scraper bug** (`scrape/store.py`): with a manifest row from CI but no local PDF, the scraper re-downloaded the file, saw a known hash and discarded the bytes, so extraction failed on the missing path. It now writes the bytes to the manifest's path when that file is absent (still never overwrites). Test added.
- **Party aliases**: DRI prints the full list names «התאחדות הספרדים שומרי תורה…» (Shas) and «הרשימה הערבית המאוחדת» (Ra'am). Neither matched, so 135 summed to 107. With the two aliases:
  - 135 sums to 120;
  - older DRI 76 is now complete (105 → 120) and joins the averages;
  - older DRI 59 improves (101 → 116) but stays in the review queue.
- **Sponsor alias**: «ערוץ 12» → `ch12` (Midgam 134).
- **Override** `data/reference/overrides/knesset_election128.json` (Maagar Mochot): the parser does not read «מספר האנשים שהשתתפו בסקר בפועל». I set respondents 2,026 and contacted 16,216 as printed on page 2, pinned to the file's sha256. Seats are as parsed.
